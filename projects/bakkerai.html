bakkerai

Een AI-chatbot voor bakkerijstudenten aan Talland College. Vragen over recepten, technieken, theorie en schoolwerk.

  • Bun
  • TypeScript
  • Elysia
  • Prisma
  • SQLite
Bekijk op GitHub

Waarom ik dit heb gemaakt

Op school zit je met een bakkerijvak dat op papier vooral uit theorie en praktijkopdrachten bestaat. Een recept dat ergens op een site staat is een mooi begin, maar wie het precies in de juiste volgorde uitvoert is een ander verhaal. Dus een chatbot die precies de recepten en de leerstof van Talland erbij kan zoeken.

Een klein project om bakkerijstudenten te helpen leren en makkelijker vragen te kunnen stellen.

Wat het doet

  • Inloggen en registreren
  • AI-chat over bakkerijgerelateerde vragen
  • Bewaart de chatgeschiedenis
  • Administratiepagina om gebruikers en chats te bekijken

De tools

De chatbot krijgt zes tools mee, en de system prompt zegt letterlijk dat hij altijd via die tools moet werken en nooit op zijn eigen kennis. Er zit geen recept of lesstof in dit project zelf; het haalt het op van svhbakkerstalent.nl.

  • getRecipesCategoriesTool — alle receptcategorieën voor een thema
  • getRecipesTool — de slugs van alle recepten in die categorie
  • getRecipeTool — één recept op basis van die slug
  • getLessonTopicsTool — de onderwerpen van leerjaar 1
  • getLessonItemsTool — de lesstukken binnen een onderwerp
  • getLessonPageTool — de inhoud van één lespagina

Elke tool is een losse functie met Playwright: inloggen, de juiste filters aanzetten, de resultaten uit de DOM lezen. De route die de AI volgt staat in de prompt, inclusief dat hij door moet blijven pagineren zolang er pagina's over zijn.

const textStream = (abortSignal: AbortSignal) =>
  streamText({
    model: groq("qwen/qwen3.6-27b"),
    abortSignal,
    tools: {
      getRecipesCategoriesTool,
      getRecipesTool,
      getRecipeTool,
      getLessonTopicsTool,
      getLessonItemsTool,
      getLessonPageTool,
    },
    stopWhen: stepCountIs(10),
    system: `
    Je bent een leer-assistent voor Talland bakkerij leerlingen. Je haalt ALTIJD
    informatie op via tools — gebruik NOOIT je eigen kennis.

    REGELS:
    - Gebruik tools direct, zonder te vragen om bevestiging
    - Noem nooit tool namen aan de gebruiker
    - Antwoord alleen op basis van tool output

De site uitlezen

Je kunt niet zomaar JSON van svhbakkerstalent.nl ophalen, dus er wordt een headless Firefox voor geopend. Eerst inloggen, dan de opslag opslaan zodat de volgende tool-call de cookie hergebruikt in plaats van opnieuw in te loggen.

TypeScriptsrc/api/svh.ts
export async function login(email: string, password: string) {
  await mutex.acquire();

  const context = await browser.newContext();

  if (await Bun.file("storage.json").exists()) {
    await context.setStorageState("storage.json");
    const crCookie = (await context.cookies()).find((c) => c.name === "CR");
    if (crCookie && (await verifyCookie(crCookie))) {
      mutex.release();
      await context.close();
      return;
    } else {
      console.log("[login] cookie invalid or expired, getting new cookie");
    }
  } else {
    console.log("[login] no storage.json found, performing full login");
  }

  const page = await context.newPage();

  try {
    await page.goto("https://svhbakkerstalent.nl/login.html");

    await page.fill("input[id='email']", email);
    await page.fill("input[class='password']", password);
    await page.click(".rememberme label");

    await page.click("input[type='submit']");

    await context.storageState({ path: "storage.json" });
  } finally {
    await context.close();
    mutex.release();
  }
}

Antwoorden komen als stream

Een recept antwoord duurt even, dus het model streamt. De chunks gaan één voor één als newline-delimited JSON naar de browser, en als de vraag van leerlingen weg is bij het sluiten van het tabblad moet de stream ook stoppen. Dat loopt via de AbortSignal van het request zelf.

TypeScriptsrc/chats.ts
const streamAbort = new AbortController();
request.signal.addEventListener("abort", () => {
  streamAbort.abort();
});

const readable = new ReadableStream({
  async start(controller) {
    const encoder = new TextEncoder();
    try {
      const stream = textStream(streamAbort.signal);
      for await (const chunk of stream.fullStream) {
        if (streamAbort.signal.aborted) return;
        controller.enqueue(encoder.encode(JSON.stringify(chunk) + "\n"));
      }
    } catch (e: any) {
      if (e.name !== "AbortError") console.error("stream error:", e);
    } finally {
      try {
        controller.close();
      } catch {}
    }
  },
  cancel() {
    streamAbort.abort();
  },
});

return new Response(readable, {
  headers: { "Content-Type": "application/x-ndjson" },
});

Gebruikers en chats

Drie tabellen en niks meer. Wachtwoorden lopen door argon2, en daarna gaat er een JWT in een httpOnly-cookie voor zeven dagen.

Prismaprisma/schema.prisma
model User {
  id       Int       @id @default(autoincrement())
  name     String
  email    String    @unique
  password String
  chats    Chat[]
  messages Message[]
}

model Chat {
  id       Int       @id @default(autoincrement())
  topic    String?
  messages Message[]
  user     User      @relation(fields: [userId], references: [id])
  userId   Int
}

model Message {
  id        Int      @id @default(autoincrement())
  content   String
  timestamp DateTime @default(now())
  user      User?    @relation(fields: [userId], references: [id])
  userId    Int?
  chat      Chat     @relation(fields: [chatId], references: [id])
  chatId    Int
}

if (!chat.topic) {
