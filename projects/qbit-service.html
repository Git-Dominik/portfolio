qbit-service

Een kleine Go-dienst die verbinding maakt met een lokale qBittorrent Web UI en een paar eenvoudige HTTP-endpoints blootstelt om torrents toe te voegen en torrentinformatie op te vragen.

  • Go
  • Gin
  • REST API
Bekijk op GitHub

Waarom ik dit heb gemaakt

Ik wilde data halen uit de API van de qBittorrent-client voor NyaasiAuto, een klein en licht programma. Maar de libraries die dit al doen zitten vol met features die ik niet nodig heb.

Uitzoeken wat ik allemaal níét nodig had leek me meer werk dan de vijf functies zelf schrijven. Dus twee endpoints, en niet meer.

Wat het doet

  • Logt in bij qBittorrent op http://localhost:8080
  • Voegt torrents toe met een magnetlink
  • Stelt torrentinformatie beschikbaar via een lokale API
  • Draait een lichte HTTP-server op poort 8081

API-endpoints

POST /add-torrent

Voegt een torrent toe op basis van een magnet-URL.

bashcurl
curl -X POST "http://localhost:8081/add-torrent" \
  -d "magnet=magnet:?xt=urn:btih:..."
Gomain.go
router.POST("/add-torrent", func(c *gin.Context) {
	magnet := c.PostForm("magnet")
	if magnet == "" {
		c.String(http.StatusBadRequest, "Missing magnet parameneter")
		return
	}

	if err := addTorrent(magnet, client); err != nil {
		fmt.Println(err)
		c.String(http.StatusInternalServerError, "Failed to submit torrent")
		return
	}

	c.String(http.StatusOK, magnet)
})

GET /info

Geeft de huidige torrentlijst uit qBittorrent terug als JSON.

bashcurl
curl http://localhost:8081/info
Gomain.go
router.GET("/info", func(c *gin.Context) {
	resp, err := client.Get("http://localhost:8080/api/v2/torrents/info")
	if err != nil {
		c.String(http.StatusInternalServerError, err.Error())
		return
	}
	defer resp.Body.Close()

	body, err := io.ReadAll(resp.Body)
	if err != nil {
		c.String(http.StatusInternalServerError, err.Error())
		return
	}

	c.Data(http.StatusOK, "application/json", body)
})

Omgevingsvariabelen

Maak een .env-bestand aan in de projectroot met:

env.env
qbUsr=your_username
qbPass=your_password

De app leest deze variabelen met godotenv.

GoloadEnv.go
type Config struct {
	Pass string
	User string
}

func loadEnv() (*Config, error) {
	if err := godotenv.Load(); err != nil {
		return nil, err
	}

	return &Config{
		Pass: os.Getenv("qbPass"),
		User: os.Getenv("qbUsr"),
	}, nil
}

Vereisten

  • Go geïnstalleerd
  • Een qBittorrent Web UI die lokaal draait op http://localhost:8080
  • Geldige qBittorrent-gebruikersnaam en -wachtwoord

Starten

bashterminal
go run .

De dienst start op http://localhost:8081.
