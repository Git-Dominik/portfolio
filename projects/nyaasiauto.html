nyaasiauto

Een klein Go-project om anime-afleveringen op nyaa.si bij te houden en nieuwe torrents automatisch naar qBittorrent te sturen.

  • Go
  • Gin
  • REST API
Bekijk op GitHub

Waarom ik dit heb gemaakt

Elke paar uur naar nyaa.si om te kijken of er iets nieuws is, was een gewoonte geworden. Dus: een script dat het voor me doet. Het kijkt naar de anime die ik volg, en zodra er een nieuwe aflevering verschijnt stuur ik die meteen door naar qBittorrent.

Het is een persoonlijk script om anime bij te houden zonder elke paar uur zelf naar nyaa.si te hoeven kijken.

Wat het doet

  • Leest de anime-doelen uit config.json
  • Controleert de nyaa.si RSS-feeds op nieuwe afleveringen
  • Matcht de ingestelde uploaders
  • Stuurt nieuwe magnetlinks naar de lokale qBittorrent-brug
  • Onthoudt de laatst geziene aflevering, zodat oude episodes niet steeds opnieuw worden toegevoegd

Hoofd-onderdelen

  • cmd/qbit-service — de lokale qBittorrent-brug
  • cmd/rss-scraper — controleert op nieuwe afleveringen en stuurt de torrents door

De brug is qbit-service, dat staat ook als los project in de map.

De feed zoeken

Per anime-titel en per uploader wordt een RSS-feed opgebouwd. De dubbele punt uit de titel gaat eruit, want die zou de zoekopdracht onleesbaar maken.

Goparser.go
func buildNyaaURL(animeTitle string, uploader string) string {
	cleanTitle := strings.ReplaceAll(animeTitle, ":", "")

	searchQuery := fmt.Sprintf("[%s] %s", uploader, cleanTitle)

	baseURL := "https://nyaa.si/?page=rss&c=0_0&f=0&q="
	return baseURL + url.QueryEscape(searchQuery)
}

Uit elke item-titel wordt het seizoen en het afleveringsnummer gehaald. De regex accepteert drie schrijfwijzen en het seizoen is optioneel:

Goparser.go
var episodeRegex = regexp.MustCompile(`(?i)(?:S(\d{1,2}))?\s*(?:E|Episode|\s+-\s+)\s*(\d{2,3})`)

func extractEpisode(title string) (int, int, bool) {
	matches := episodeRegex.FindStringSubmatch(title)

	if len(matches) < 3 {
		return 0, 0, false
	}

	season := 1
	if matches[1] != "" {
		season, _ = strconv.Atoi(matches[1])
	}

	episode, err := strconv.Atoi(matches[2])
	if err != nil {
		return 0, 0, false
	}

	return season, episode, true
}

Een nieuwe aflevering herkennen

Het script zoekt niet de nieuwste aflevering, maar precies de volgende: seizoen en afleveringsnummer uit config.json, plus één. Alleen bij een exacte match gaat er iets door naar de brug.

Gomain.go
expectedSeason := targets[i].LatestSeen.Season
expectedEpisode := targets[i].LatestSeen.Episode + 1

for _, item := range feed.Items {
	season, episode, found := extractEpisode(item.Title)
	if !found {
		continue
	}

	if season == expectedSeason && episode == expectedEpisode {
		if err := torrentLinks(item.Link); err != nil {
			fmt.Println("Failed to add torrent, make sure qbit-service is running")
			continue
		}

		episodeTag := fmt.Sprintf("S%02dE%02d", season, episode)
		fmt.Println("[NEW EPISODE]", episodeTag, item.Title)
		fmt.Println(item.Link)

		targets[i].LatestSeen.Season = season
		targets[i].LatestSeen.Episode = episode
		targets[i].saveProgress(configFilePath, targets)
		fmt.Println(targets[i].LatestSeen)
		break
	}
}

De hele lijst wordt daarna teruggeschreven naar config.json, zodat de voortgang de volke ronde overleeft:

Goconfig.go
func (t *Target) saveProgress(configFilePath string, targets []Target) error {
	updateJson, err := json.MarshalIndent(targets, "", " ")
	if err != nil {
		fmt.Println(err)
	}

	return os.WriteFile(configFilePath, updateJson, 0644)
}

Vereisten

  • Go geïnstalleerd
  • Een qBittorrent Web UI die lokaal draait

Een .env-bestand in cmd/qbit-service:

envcmd/qbit-service/.env
qbUsr=your_username
qbPass=your_password

Een config.json in de projectroot met je animelijst:

jsonconfig.json
[
  {
    "title": "Anime Title 1",
    "uploaders": ["UploaderA", "UploaderB"],
    "latest_seen": {
      "season": 1,
      "episode": 12
    }
  },
  {
    "title": "Anime Title 2",
    "uploaders": ["UploaderA", "UploaderB"],
    "latest_seen": {
      "season": 2,
      "episode": 5
    }
  }
]

Je kunt zo veel anime-titels toevoegen als je wilt.

Starten

Start eerst de qBittorrent-brug:

bashterminal
go run cmd/qbit-service

En daarna de scraper:

bashterminal
go run cmd/rss-scraper

Wat er nog niet is

  • De eerste uploader die matcht wint. De uploaders gaan op volgorde langs en zodra er iets gevonden is stopt de lus. De rest van de lijst wordt die ronde niet eens gecontroleerd.
  • De regex mist veel schrijfwijzen. S01E02, Episode 05 en - 12 worden herkend, een kale 12 of 1x12 niet. Staat het seizoen er niet, dan wordt het seizoen 1.
